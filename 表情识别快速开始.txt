  ⭐         😐 平静 (neutral)        - 正常状态

如果安装了 pyJianYingDraft，可以自动生成剪映草稿：

    from src.emotion_detector import analyze_video_emotions
    from pyJianYingDraft import ScriptFile, trange, FilterType
    
    # 1. 分析视频
    video_path = "主播名_2025-10-30_完整.ts"
    highlights = analyze_video_emotions(video_path, top_n=10)
    
    # 2. 创建剪映草稿
    draft = ScriptFile()
    
    for start, end, emotion in highlights:
        seg = draft.add_video(video_path, trange(start, end))
        
        # 根据表情添加滤镜
        if emotion == 'happy':
            seg.add_filter(FilterType.甜美, 70)
    
    # 3. 导出草稿
    draft.export("可爱表情集锦")
    
    print("✅ 在剪映中打开草稿文件即可编辑和导出！")

1. 视频质量要求：
   ✅ 主播脸部清晰
   ✅ 光线充足
   ❌ 不要过暗或逆光

2. 必须安装 fer 库：
   pip install fer
   否则只能检测人脸，无法识别表情

3. 处理时间较长：
   不建议实时处理
   建议录制完成后离线分析

4. 识别准确性：
   AI识别有一定误差
   建议结合人工筛选

  ❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 提示"未检测到任何表情数据"？
A: 可能原因：
   1. 视频中没有清晰的人脸
   2. 未安装 fer 库
   3. 视频质量太低

Q: 分析速度太慢？
A: 尝试增大 sample_rate 参数：
   sample_rate=60  # 从30改为60

Q: 识别不准确？
A: 这是正常的AI识别误差
   建议人工筛选结果

Q: 支持实时识别吗？
A: 技术上可以，但太慢，不推荐
