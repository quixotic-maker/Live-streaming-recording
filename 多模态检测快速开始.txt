✨ 核心理念：不是通用的表情识别，而是针对主播的定制检测！

  🎯 检测维度（5个维度融合）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🎤 语音对话分析
   - 识别主播说的特定话语
   - 例如："哈哈哈"、"笑死"、"我的天"
   - 根据您的经验设置触发关键词
   - 权重：3-5分

2. 🎁 礼物特效检测
   - 检测画面中的礼物动画
   - 送礼物时必有精彩反应
   - 通过颜色和画面变化识别
   - 权重：3-5分

3. ⏰ 时间规律加权
   - 前20分钟几乎全是表情包
   - 开播初期权重翻倍(x2.0)
   - 之后逐渐衰减
   - 极其重要的维度！

4. 😊 表情识别（辅助）
   - AI识别主播表情
   - 作为辅助判断
   - 权重：2-3分

5. 💬 弹幕爆发（可选）
   - 如果有弹幕数据
   - 观众互动高峰
   - 权重：可变

综合得分 = (语音+礼物+表情+弹幕) × 时间权重

基础使用：

    from src.multimodal_detector import MultimodalDetector
    
    # 创建检测器
    detector = MultimodalDetector("山山")
    
    # 多模态分析
    highlights = detector.fusion_analysis("video.mp4")
    
    # 查看结果
    for start, end, details in highlights[:10]:
        print(f"{start:.1f}s-{end:.1f}s: 得分{details['score']:.1f}")

结合剪映草稿：

    from pyJianYingDraft import ScriptFile, trange, FilterType
    
    # 分析视频
    highlights = detector.fusion_analysis("video.mp4")
    
    # 创建草稿
    draft = ScriptFile()
    for start, end, details in highlights[:10]:
        seg = draft.add_video("video.mp4", trange(start, end))
        if details['score'] > 30:
            seg.add_filter(FilterType.赛博朋克, 70)
    
    draft.export("精彩集锦")

  💡 使用建议
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 关键词设置
   ✓ 至少设置10-20个关键词
   ✓ 涵盖：笑声、惊讶、可爱、互动等类型
   ✓ 根据分析结果持续优化

2. 首次使用
   ✓ 先用简化模式快速测试
   ✓ 查看结果是否符合预期
   ✓ 再考虑是否使用完整模式

3. 调优策略
   ✓ 如果漏掉精彩片段：增加关键词
   ✓ 如果误判太多：提高得分阈值
   ✓ 结合实际效果持续调整

  ⚠️ 注意事项

1. 语音识别（Whisper）
   - 首次使用会下载模型（约140MB）
   - 需要一定处理时间
   - 可选功能，不影响其他检测

2. 处理时间
   - 完整模式较慢，建议离线处理
   - 可先用简化模式快速测试
   - GPU可加速语音识别

3. 主播配置
   - 配置文件在 config/anchors/
   - 可以随时编辑修改
   - 重启检测器后生效
