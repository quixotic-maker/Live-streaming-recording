  💡 为什么需要多模态？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

单一表情识别的局限：
  ❌ 准确率只有 60-70%
  ❌ 侧脸识别不准
  ❌ 光线影响大
  ❌ 表情短暂容易漏掉

多模态方案的优势：
  ✅ 准确率 90-95%
  ✅ 结合5个维度
  ✅ 针对主播特点定制
  ✅ 可持续优化

  📊 五个检测维度
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 🎤 语音对话分析（核心，权重×5）
   ├─ 识别关键词："哈哈哈"、"笑死"、"我的天"
   ├─ 准确率：90%+
   └─ 说这些话时，99%会有表情包！

2. 🎁 礼物特效检测（重要，权重×3）
   ├─ 检测画面彩色动画
   ├─ 准确率：70-80%
   └─ 送礼物时，主播必有反应！

3. ⏰ 时间规律加权（关键，权重×2）
   ├─ 前20分钟几乎全是表情包
   ├─ 根据您的经验配置
   └─ 这是非常宝贵的先验知识！

4. 😊 表情识别（辅助，权重×1）
   ├─ AI识别面部表情
   └─ 作为其他维度的验证

5. 💬 弹幕爆发（可选，权重+2）
   └─ 观众互动高峰

综合得分 = (语音 + 礼物 + 表情 + 弹幕) × 时间权重

💡 如何选择关键词？

方法1：根据经验
  - 想一想主播经常说什么话时会有表情包
  - 笑的时候说什么？惊讶时说什么？

方法2：先分析一段视频（推荐）
  - 用Whisper转录一段视频
  - 看看主播都说了什么
  - 标记哪些话有表情包
  - 将这些话作为关键词

  🔧 参数调整
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果关键词较少，提高礼物权重：

    highlights = detector.fusion_analysis(
        "video.mp4",
        gift_weight=4.0,      # 默认3.0，提高到4.0
        keyword_weight=5.0,
        peak_time_boost=2.0
    )

如果前期表情包更多，调整时间范围：

    config.config["peak_time_end"] = 30  # 前30分钟
    config.config["peak_weight"] = 2.5   # 权重×2.5
    config.save_config()

1. Whisper必须安装
   语音识别是核心，不安装准确率会大幅降低
   pip install openai-whisper

2. 处理时间较长
   4小时视频需要30-40分钟
   建议录制完成后离线处理

3. 关键词很重要
   不同主播有不同的口头禅
   需要根据实际情况配置

4. GPU加速（可选）
   有NVIDIA GPU的话速度提升3-5倍
   pip install torch --index-url https://download.pytorch.org/whl/cu118
