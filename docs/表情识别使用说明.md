# 🎭 表情识别精彩片段提取功能

## 功能介绍

**自动检测主播的可爱表情，并将这些时刻提取为精彩片段！**

通过AI人脸识别和表情分析技术，自动识别直播视频中主播的：
- 😊 微笑时刻
- 😄 大笑瞬间
- 😮 惊讶反应
- 😱 惊吓表情
- 😢 感动时刻
- 更多...

### 方法2：详细控制

```python
from src.emotion_detector import EmotionDetector

# 1. 创建检测器
detector = EmotionDetector()
detector.initialize()

# 2. 分析视频（返回完整时间线）
emotion_timeline = detector.analyze_video(
    "video.mp4",
    sample_rate=15  # 每15帧（约0.5秒）分析一次
)

# 3. 提取精彩片段
highlights = detector.find_highlights_by_emotion(
    emotion_timeline,
    min_duration=3.0,  # 最短片段3秒
    merge_gap=2.0      # 2秒内的片段自动合并
)

# 4. 处理结果
for start, end, emotion, intensity in highlights:
    duration = end - start
    print(f"{start:.1f}s-{end:.1f}s ({duration:.1f}秒): "
          f"{emotion} 强度:{intensity:.2f}")
```

## ⚙️ 参数说明

### analyze_video() 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| video_path | str | 必需 | 视频文件路径 |
| sample_rate | int | 30 | 采样率（每N帧分析一次） |

**采样率建议**：
- `15` - 高精度（约0.5秒一次，速度较慢）
- `30` - 推荐（约1秒一次，平衡效果和速度）
- `60` - 快速（约2秒一次，可能漏掉短暂表情）

### find_highlights_by_emotion() 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| emotion_timeline | list | 必需 | 表情时间线数据 |
| min_duration | float | 3.0 | 最短片段时长（秒） |
| merge_gap | float | 2.0 | 合并间隔（秒） |

**参数建议**：
- `min_duration=3.0` - 短视频片段（3-5秒）
- `min_duration=5.0` - 中等片段（5-10秒）
- `min_duration=10.0` - 长片段（10+秒）

## 🎬 与剪映集成

### 自动生成精彩集锦草稿

```python
from src.emotion_detector import analyze_video_emotions
from pyJianYingDraft import ScriptFile, VideoSegment, FilterType

# 1. 分析视频找精彩片段
video_path = "主播名_2025-10-30_完整.ts"
highlights = analyze_video_emotions(video_path, top_n=10)

# 2. 创建剪映草稿
draft = ScriptFile()

# 3. 添加精彩片段
for i, (start, end, emotion) in enumerate(highlights):
    # 添加视频片段
    seg = draft.add_video(
        video_path,
        trange(start, end),
        track_name="highlights"
    )
    
    # 根据表情类型添加不同滤镜
    if emotion == 'happy':
        seg.add_filter(FilterType.甜美, 70)
    elif emotion == 'surprise':
        seg.add_filter(FilterType.赛博朋克, 60)
    elif emotion == 'fear':
        seg.add_filter(FilterType.黑白, 50)
    
    # 添加入场动画
    seg.add_animation(VideoIntro.放大模糊)

# 4. 导出草稿
draft.export("可爱表情集锦")
print("✅ 剪映草稿已生成！在剪映中打开即可编辑")
```

## 💡 实际应用示例

### 示例1：每日自动生成精彩集锦

```python
import os
from datetime import datetime
from src.emotion_detector import analyze_video_emotions
from pyJianYingDraft import ScriptFile

def auto_create_cute_moments(video_path):
    """自动创建可爱瞬间集锦"""
    
    print(f"🔍 分析视频: {os.path.basename(video_path)}")
    
    # 1. 提取精彩片段
    highlights = analyze_video_emotions(video_path, top_n=15)
    
    if not highlights:
        print("⚠️ 未找到精彩片段")
        return
    
    print(f"✅ 找到 {len(highlights)} 个精彩片段")
    
    # 2. 创建剪映草稿
    draft = ScriptFile()
    
    for start, end, emotion in highlights:
        seg = draft.add_video(video_path, trange(start, end))
        
        # 根据表情添加效果
        if emotion == 'happy':
            seg.add_filter(FilterType.甜美, 70)
        elif emotion == 'surprise':
            seg.add_filter(FilterType.活力, 60)
    
    # 3. 导出
    date_str = datetime.now().strftime('%Y%m%d')
    draft_name = f"可爱瞬间_{date_str}"
    draft.export(draft_name)
    
    print(f"📦 草稿已生成: {draft_name}.jianying")
    print("👉 在剪映中打开即可查看和导出！")

# 使用
auto_create_cute_moments("主播名_2025-10-30_完整.ts")
```

## ⚠️ 注意事项

### 1. 视频质量要求
- ✅ 主播脸部清晰可见
- ✅ 光线充足
- ✅ 镜头稳定
- ❌ 过暗或过曝光
- ❌ 脸部被遮挡
- ❌ 镜头晃动严重

### 2. 识别准确性
- 正脸识别准确率：85-95%
- 侧脸识别准确率：60-80%
- 多人画面：可能识别不准

### 3. 处理时间
- 4小时视频约需15-20分钟分析
- 建议在录制完成后离线处理
- 不建议实时处理（太慢）

### 4. 依赖安装
必须安装 `fer` 库才能进行表情识别，否则只能做人脸检测：

```bash
# 完整功能
pip install fer

# 只有人脸检测（功能受限）
pip install opencv-python
```

## 🐛 常见问题

**Q: 提示"未检测到任何表情数据"？**  
A: 可能原因：
1. 视频中没有清晰的人脸
2. 光线太暗
3. 未安装 `fer` 库

**Q: 分析速度太慢？**  
A: 尝试：
1. 增大 `sample_rate`（如60）
2. 只分析部分视频
3. 使用更好的硬件

**Q: 识别的表情不准确？**  
A: 这是AI的正常现象，建议：
1. 设置更高的置信度阈值
2. 结合弹幕/音量等其他指标
3. 人工筛选结果

**Q: 可以实时识别吗？**  
A: 理论可以，但不推荐。表情识别比较慢，建议离线处理。

**Q: 支持GPU加速吗？**  
A: 支持，但需要安装 TensorFlow GPU 版本，配置较复杂。

## 📚 技术原理

### 工作流程

```
视频输入
  ↓
每N帧提取一帧
  ↓
人脸检测（OpenCV Haar Cascade）
  ↓
表情识别（FER深度学习模型）
  ↓
返回7种表情的置信度
  ↓
选择置信度最高的表情
  ↓
标记精彩表情时刻
  ↓
合并连续片段
  ↓
返回精彩片段列表
```

### 使用的技术

- **人脸检测**: OpenCV Haar Cascade
- **表情识别**: FER库（基于深度学习）
- **模型**: 预训练的CNN模型
- **识别类别**: 7种基本表情
