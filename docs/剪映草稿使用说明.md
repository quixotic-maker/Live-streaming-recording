# 剪映草稿生成系统使用说明

## 📋 功能概述

**剪映草稿生成系统**可以自动生成剪映专业版可识别的草稿文件，实现：
- ✅ 自动视频分段和排序
- ✅ 智能添加字幕标记
- ✅ 预设时间线和轨道
- ✅ 无需手动导入和剪辑

---

## 🎯 支持的草稿类型

### 1. **歌曲集锦草稿** (`生成剪映草稿_歌曲集锦.py`)
**功能：**
- 基于识别的125首歌曲生成集锦
- 每首歌自动添加歌名字幕
- 支持精选模式（10首）和完整模式（全部）

**使用场景：**
- 制作歌曲合集视频
- 快速生成精华内容
- 展示演唱片段

### 2. **完整分段草稿** (`生成剪映草稿_完整分段.py`)
**功能：**
- 按内容类型（唱歌/礼物/闲聊）自动分段
- 每个片段添加类型标记
- 保留完整时间线

**使用场景：**
- 完整视频的二次剪辑
- 按类型提取片段
- 精细化编辑

## 💡 进阶使用

修改脚本中的字幕样式参数：

```python

    text=f"♪ {title} ♪",
    start=...,
    duration=...,
    style={

        "font_size": 40.0,       # 字体大小
        "color": [255, 215, 0],  # RGB颜色（金色）
```

### **修改视频路径**

```python

video_path = "/你的视频路径/视频.mp4"
```

### **调整草稿输出位置**

```python
output_dir = "/你的输出目录/剪映草稿"
```

### **限制片段数量**

对于完整分段草稿，避免过大：

```python

max_segments = 100  # 最多100个片段
```

## ❓ 常见问题

### **Q1: 剪映无法识别草稿？**
**A:** 检查以下几点：
1. 确保剪映版本 ≥ 6.0
2. 草稿目录结构完整（包含两个JSON文件）
3. 视频文件路径正确且可访问
4. 尝试直接在剪映中"打开草稿"而非复制

### **Q2: 视频无法加载？**
**A:** 
- 确认视频文件路径在草稿中是绝对路径
- 视频文件未被移动或删除
- 视频格式被剪映支持（MP4/MOV等）

### **Q3: 字幕位置不理想？**
**A:**
- 导入草稿后，在剪映中手动调整字幕位置
- 或修改脚本中的 `transform` 参数

### **Q4: 生成的草稿太大？**
**A:**
- 使用精选模式而非完整模式
- 减少 `max_segments` 参数
- 分多个草稿生成

### **Q5: 想要添加背景音乐？**
**A:**
- 导入草稿后，在剪映中手动添加音频轨道
- 或修改 `jianying_draft.py` 添加 `add_audio_material` 支持
