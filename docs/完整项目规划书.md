# 抖音直播素材智能管理系统 - 完整项目规划书

## 📋 项目总览

**项目目标：** 从抖音直播录制视频中自动提取、分类、管理各类素材，并支持自动化视频编辑

**核心价值：**
- 自动化处理4小时直播录像
- 智能识别125首歌曲
- 提取200+个表情包素材
- 生成可编辑的剪映草稿
- 构建分层素材管理系统

## 📊 数据流转全链路

### 链路1：从录制到语音分析

```
1. 直播录制
   输入：抖音直播流
   工具：main.py + FFmpeg
   输出：观山_2025-10-30.mp4 (4小时视频)
   
2. 视频分段
   输入：完整视频
   工具：FFmpeg自动分段
   输出：观山_2025-10-30_part1.ts, part2.ts...
   
3. 视频合并
   输入：分段.ts文件
   工具：src/video_merger.py
   输出：观山_2025-10-30_完整.ts
   
4. 音频提取
   输入：完整视频
   工具：FFmpeg -vn
   输出：观山_2025-10-30_audio.wav
   
5. 语音转文字
   输入：audio.wav
   工具：Whisper (large-v2模型)
   输出：speech_analysis_完整转录.json (4907段)
   
6. 内容分类
   输入：speech_analysis_完整转录.json
   工具：src/content_classifier.py
   输出：
     - singing_素材.json (2156段歌曲片段)
     - gift_素材.json (74个感谢时刻)
     - chat_素材.json (1843段闲聊)
     - unknown_素材.json (834段未知)
```

### 链路2：从语音分析到歌曲库

```
7. 歌曲识别
   输入：singing_素材.json
   工具：整理歌曲素材.py
   输出：
     - 歌曲素材库/歌曲列表.json (125首歌)
     - 歌曲素材库/歌曲列表.txt
     - 歌曲素材库/提取歌曲.sh
   
8. 歌曲视频提取
   输入：歌曲列表.json + 原视频
   工具：FFmpeg -ss -t -c copy
   执行：bash 提取歌曲.sh
   输出：歌曲素材库/视频/歌曲001.mp4 ~ 歌曲125.mp4
   
9. 歌曲音频提取
   输入：歌曲视频
   工具：FFmpeg -vn -acodec libmp3lame
   输出：歌曲素材库/音频/歌曲001.mp3 ~ 歌曲125.mp3
   
10. 歌曲元数据生成
    输入：所有歌曲文件
    工具：src/material_organizer.py
    输出：歌曲索引.json
      {
        "song_001": {
          "name": "可能",
          "duration": 245.3,
          "start_time": "19:15:23",
          "video_path": "歌曲素材库/视频/歌曲001.mp4",
          "audio_path": "歌曲素材库/音频/歌曲001.mp3",
          "lyrics": "...",
          "tags": ["流行", "情歌"]
        }
      }
```

### 链路3：从视频到表情包库

```
11. 手势舞检测（方案A）
    输入：原视频 0-60分钟片段
    工具：src/gesture_detector.py - MotionDetector
    处理：
      - 每5秒采样一次（720个点）
      - 计算帧差运动强度
      - 上半身ROI分析
    输出：手势舞候选.json (15-25个片段)
    
12. 手势精确识别（方案B）
    输入：手势舞候选.json + 原视频
    工具：src/gesture_detector.py - PoseDetector
    处理：
      - MediaPipe手部检测
      - 识别比心/挥手/招手
      - 置信度评分
    输出：手势识别结果.json (10-15个确认)
    
13. 感谢时刻分析（方案C）
    输入：gift_素材.json (74个) + 原视频
    工具：src/gesture_detector.py - MultimodalDetector
    处理：
      - 时间窗口：关键词±3秒
      - 表情检测：happy/surprise
      - 手势检测：挥手/比心
      - 特效检测：礼物特效
      - 综合评分：0-1.0
    输出：感谢表情候选.json (50-60个推荐)
    
14. 表情包生成
    输入：所有候选 + 原视频
    工具：src/emoji_generator.py
    处理：
      - 提取帧序列（15fps）
      - 生成3种规格GIF：240x240, 300x300, 512x512
      - 压缩优化：<1MB
      - 生成高清截图：1920x1080
    输出：
      - 临时文件/emoji_001_240x240.gif
      - 临时文件/emoji_001_300x300.gif
      - 临时文件/emoji_001_512x512.gif
      - 临时文件/emoji_001_hd.png
    
15. 表情包分类存储
    输入：临时文件/*.gif + 元数据
    工具：src/material_organizer.py
    处理：
      - 按类型分类：手势舞/感谢/比心
      - 按规格分类：小/中/大
      - 生成缩略图
      - 生成元数据
    输出：
      素材库/表情包站/
      ├─ 抖音专用/
      │   ├─ 手势舞/
      │   │   ├─ 240x240/ (10-15个)
      │   │   ├─ 300x300/ (10-15个)
      │   │   └─ 512x512/ (10-15个)
      │   ├─ 感谢表情/
      │   │   ├─ 240x240/ (50-60个)
      │   │   ├─ 300x300/ (50-60个)
      │   │   └─ 512x512/ (50-60个)
      │   └─ 比心手势/
      │       ├─ 240x240/ (3-5个)
      │       ├─ 300x300/ (3-5个)
      │       └─ 512x512/ (3-5个)
      └─ 高清截图/
          ├─ 手势特写/ (100-150张)
          └─ 表情特写/ (100-150张)
      
16. 表情包索引生成
    输入：所有表情包文件
    工具：src/material_organizer.py
    输出：素材库/元数据库/表情包索引.json
      {
        "emoji_001": {
          "type": "手势舞",
          "source_time": 125.5,
          "duration": 3.0,
          "specs": {
            "small": "240x240/emoji_001.gif",
            "medium": "300x300/emoji_001.gif",
            "large": "512x512/emoji_001.gif"
          },
          "file_sizes": {
            "small": "450KB",
            "medium": "720KB",
            "large": "980KB"
          },
          "features": {
            "has_smile": true,
            "has_gesture": true,
            "gesture_type": "wave"
          },
          "tags": ["手势舞", "唱歌", "开场"],
          "confidence": 0.87
        }
      }
```

### 链路4：从素材库到剪映草稿

```
17. 创建剪映项目结构
    输入：无
    工具：src/jianying_draft.py - DraftCreator
    处理：
      - 创建.jianying文件夹
      - 创建draft_content.json
      - 创建draft_meta_info.json
    输出：草稿_观山_2025-10-30.jianying/
    
18. 导入素材到草稿
    输入：素材库各类文件
    工具：src/jianying_draft.py - MaterialImporter
    处理：
      - 复制到草稿素材文件夹
      - 生成素材ID映射
      - 创建素材清单
    输出：
      草稿_观山_2025-10-30.jianying/
      └─ 素材/
          ├─ 视频/ (125个歌曲视频)
          ├─ 音频/ (125个歌曲音频)
          ├─ 图片/ (200+表情包)
          └─ material_list.json
    
19. 生成字幕轨道
    输入：speech_analysis_完整转录.json
    工具：src/jianying_draft.py - SubtitleGenerator
    处理：
      - 读取Whisper转录
      - 转换为剪映字幕格式
      - 设置时间轴对齐
      - 应用字幕样式
    输出：draft_content.json (包含字幕轨道)
    
20. 生成视频时间轴
    输入：歌曲列表.json + 内容分类结果
    工具：src/jianying_draft.py - TimelineGenerator
    处理方案A - 完整直播草稿：
      - 导入完整视频
      - 添加章节标记（125首歌）
      - 添加字幕
      - 标记高光时刻
    
    处理方案B - 歌曲合集草稿：
      - 依次导入125个歌曲视频
      - 添加转场效果
      - 添加片头片尾
      - 添加歌名字幕
    
    处理方案C - 高光合集草稿：
      - 导入TOP50高光片段
      - 按时间排序或按类型分组
      - 添加BGM
      - 添加特效转场
    
    输出：draft_content.json (完整时间轴)
    
21. 应用特效模板
    输入：draft_content.json
    工具：src/jianying_draft.py - EffectApplier
    处理：
      - 片头：Logo动画 + 标题
      - 转场：淡入淡出、交叉溶解
      - 贴纸：表情包覆盖
      - 滤镜：美颜、调色
      - 片尾：关注提醒
    输出：draft_content.json (包含特效)
    
22. 导出剪映草稿
    输入：完整draft_content.json
    工具：src/jianying_draft.py - DraftExporter
    输出：
      草稿_观山_2025-10-30_完整直播.jianying
      草稿_观山_2025-10-30_歌曲合集.jianying
      草稿_观山_2025-10-30_高光合集.jianying
```
