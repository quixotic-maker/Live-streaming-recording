# 抖音直播素材智能管理系统 - 总结与使用指南

## 🎯 系统概述

本系统实现了从抖音直播录制到素材管理的完整自动化流程，包含：
1. ✅ 时间窗口监测录制（19:01-23:30自动录制）
2. ✅ 语音转文字分析（Whisper，4907段）
3. ✅ 内容智能分类（唱歌/礼物/闲聊）
4. ✅ 歌曲自动识别（125首完整歌曲）
5. ✅ 表情包智能生成（3种检测方案）
6. ⏳ 素材提取管理（音频/截图/集锦）
7. ⏳ 剪映草稿生成（自动化编辑）

## 🚀 快速开始

### 步骤1：环境准备

```bash
# 安装基础依赖
pip install -r requirements.txt

# 安装表情包生成依赖
pip install -r requirements_emoji.txt

# 可选：安装MediaPipe（精确手势识别）
pip install mediapipe>=0.10.0
```

### 步骤2：直播录制

```bash
# 启动自动录制（每天19:01-23:30）
python main.py
```

**输出：**
- 视频文件：`观山_2025-10-30_完整.ts`
- 录制日志：`logs/streamget.log`

### 步骤3：语音分析

```bash
# 完整转录（首次运行，需20-30分钟）
python 完整语音分析.py
```

**输出：**
- `speech_analysis_完整转录.json` - 4907段语音
- `speech_analysis_纯文本.txt` - 纯文本
- `speech_analysis_精彩时刻.txt` - 高频词汇

### 步骤4：内容分类

```bash
# 自动分类（唱歌/礼物/闲聊）
python -c "from src.content_classifier import ContentClassifier; ..."
```

**输出：**
- `素材库/singing_素材.json` - 2156段唱歌
- `素材库/gift_素材.json` - 74个感谢时刻
- `素材库/chat_素材.json` - 1843段闲聊

### 步骤5：歌曲识别

```bash
# 识别完整歌曲
python 整理歌曲素材.py
```

**输出：**
- `歌曲素材库/歌曲列表.json` - 125首歌
- `歌曲素材库/提取歌曲.sh` - 批量提取脚本

### 步骤6：表情包生成 ⭐ 核心功能

```bash
# 先测试规格（可选）
python 测试抖音表情包规格.py

# 生成所有表情包（40-60分钟）
python 生成表情包素材.py
```

**输出：**
- `素材库/表情包站/` - 600-750个GIF文件
- `素材库/元数据库/表情包索引.json` - 元数据
- `素材库/下载所有表情包.sh` - 下载脚本

### 步骤7：素材提取

```bash
# 提取歌曲音频
python 批量提取歌曲音频.py

# 选择格式：1=MP3, 2=FLAC, 3=两者
# 输入：1
```

**输出：**
- `素材库/歌曲站/音频/MP3/` - 125首MP3
- `素材库/歌曲站/音频/FLAC/` - 125首FLAC（可选）

```python
# 修改 生成表情包素材.py

# 调整运动检测阈值
motion_detector = MotionDetector({
    "motion_threshold": 0.12,  # 降低阈值，找到更多候选
    "min_duration": 1.5        # 最短1.5秒

# 调整多模态权重
multimodal_detector = MultimodalDetector({
    "emotion_weight": 0.2,
    "gesture_weight": 0.5,     # 增加手势权重
    "effect_weight": 0.3       # 增加特效权重
})
```

### 2. 批量生成自定义GIF

```python
from src.emoji_generator import EmojiGenerator

generator = EmojiGenerator()

# 自定义时间点
custom_moments = [
    {"start": 125.5, "end": 128.5, "name": "custom_001"},
    {"start": 256.3, "end": 258.8, "name": "custom_002"},
]

for moment in custom_moments:
    result = generator.generate_multi_specs(
        video_path="视频.mp4",
        start=moment["start"],
        end=moment["end"],
        output_dir="custom_output",
        base_name=moment["name"]
    )
```

## ❓ 常见问题

### Q1: 表情包生成太慢？

**A:** 跳过姿态估计（方案B）：
```python
# 在 生成表情包素材.py 中注释掉
# self.identify_gestures()
```

### Q2: GIF文件太大？

**A:** 调整生成参数：
```python
generator = EmojiGenerator({
    "default_fps": 10,      # 降低帧率
    "max_size_kb": 800      # 降低目标大小
})
```

### Q3: 找不到足够的手势舞？

**A:** 降低检测阈值：
```python
detector = MotionDetector({
    "motion_threshold": 0.10  # 从0.15降到0.10
})
```

### Q4: 如何只生成某种类型的表情包？

**A:** 修改候选列表：
```python
# 只生成感谢表情
all_candidates = []
for moment in self.thank_moments[:50]:
    all_candidates.append({...})
# 不添加手势舞
```
