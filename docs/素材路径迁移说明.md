## ⏰ 设置定时同步到 `/mnt/storage/shanshan/`

### **方法1：手动同步（推荐测试）**
```bash
bash 同步到storage定时任务.sh
# 查看日志
cat ~/sync_to_storage.log
```

### **方法2：定时任务（需要管理员配置权限）**

**步骤1：测试权限**
```bash
# 测试能否写入目标目录
touch /mnt/storage/shanshan/test.txt 2>&1
```

如果报错 "Permission denied"，需要管理员执行：
```bash
# 管理员在宿主机执行（不是容器内）
sudo chown -R liu:liu /mnt/storage/shanshan
# 或
sudo chmod 777 /mnt/storage/shanshan
```

**步骤2：设置定时任务**
```bash
# 编辑定时任务
crontab -e

# 添加以下行（每30分钟同步一次）
*/30 * * * * /home/liu/app_github/DouyinLiveRecorder/同步到storage定时任务.sh

# 或每小时同步（在整点）
0 * * * * /home/liu/app_github/DouyinLiveRecorder/同步到storage定时任务.sh

# 或每天凌晨2点同步
0 2 * * * /home/liu/app_github/DouyinLiveRecorder/同步到storage定时任务.sh
```

**步骤3：查看定时任务状态**
```bash
# 列出当前定时任务
crontab -l

# 查看同步日志
tail -f ~/sync_to_storage.log
```

## ⚠️ 权限问题说明

### **问题现象**
```
cp: 无法创建普通文件 '/mnt/storage/shanshan/xxx': 权限不够
```

### **原因**
- 运行在 Docker 容器内，容器配置了 `no new privileges` 安全限制
- `/mnt/storage/shanshan/` 是 root 拥有的目录
- 容器内无法使用 `sudo` 提升权限

### **解决方案**

**方案A：使用本地目录（当前方案）✅**
```bash
# 所有素材都在用户目录
~/shanshan_materials/

# 您自己写脚本定时同步到 /mnt/storage/shanshan/
# 可以在容器外（宿主机）运行同步脚本
```

**方案B：管理员修改权限**
```bash
# 管理员在宿主机执行
sudo chown -R liu:liu /mnt/storage/shanshan
```

**方案C：创建软链接**
```bash
# 管理员在宿主机执行
sudo ln -s /home/liu/shanshan_materials /mnt/storage/shanshan
```
