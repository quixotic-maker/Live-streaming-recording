# 表情包生成系统 - 使用说明

## 📋 系统概述

表情包生成系统能够从抖音直播录制视频中自动识别、提取、生成适合抖音平台的表情包（GIF动图）。

**核心功能：**
- 🎯 智能检测手势舞和感谢时刻
- 🎨 生成多规格GIF（240x240, 300x300, 512x512）
- 📁 自动分类存储
- 📊 元数据索引管理
- 🔧 规格测试和优化

运行完整流程：


7. **生成报告** - 创建索引和统计

**总耗时：** 约40-60分钟（取决于候选数量）

## 🎯 核心模块说明

### 1. 手势检测器（gesture_detector.py）

**三种检测方案：**

#### 方案A: 运动检测（MotionDetector）

**用途：** 快速粗筛，找出所有手势舞候选片段

**原理：**
- 每5秒采样一次
- 计算相邻帧的差值
- 检测上半身区域（y: 0-50%）
- 运动强度 > 阈值 → 候选片段

**示例：**
```python
from src.gesture_detector import MotionDetector

detector = MotionDetector()
dance_moments = detector.detect_dance_moments(
    video_path="视频.mp4",
    start_time=0,
    end_time=3600  # 前60分钟
)

print(f"找到 {len(dance_moments)} 个手势舞")
```

#### 方案B: 姿态估计（PoseDetector）

**用途：** 精确识别具体手势类型

**要求：** 需要安装MediaPipe

**识别类型：**
- 比心（heart）
- 挥手（wave）
- 手势舞（dance）

**示例：**
```python
from src.gesture_detector import PoseDetector

detector = PoseDetector()
result = detector.identify_gesture(
    video_path="视频.mp4",
    start=125.5,
    end=128.5
)

print(f"手势类型: {result['gesture_type']}")
print(f"置信度: {result['confidence']}")
```

#### 方案C: 多模态检测（MultimodalDetector）

**用途：** 综合分析感谢时刻

**检测维度：**
1. 表情检测（happy/surprise）- 30%
2. 手势检测（挥手/比心）- 40%
3. 特效检测（礼物特效）- 20%
4. 关键词匹配（"谢谢"）- 10%

**示例：**
```python
from src.gesture_detector import MultimodalDetector

detector = MultimodalDetector()
result = detector.analyze_thank_moment(
    video_path="视频.mp4",
    time=132.5,  # 关键词时间
    keyword="谢谢"
)

print(f"综合得分: {result['best_moment']['score']}")
print(f"是否推荐: {result['recommended']}")
```

### 2. 表情包生成器（emoji_generator.py）

**功能：**
- 提取视频帧序列
- 生成多规格GIF
- 压缩优化文件大小
- 生成高清静态图

**示例：**
```python
from src.emoji_generator import EmojiGenerator

generator = EmojiGenerator()

# 生成多规格表情包
result = generator.generate_multi_specs(
    video_path="视频.mp4",
    start=125.5,
    end=128.5,
    output_dir="output",
    base_name="emoji_001"
)

print(f"生成了 {len(result['gifs'])} 种规格")
for spec_name, gif_info in result['gifs'].items():
    print(f"  {spec_name}: {gif_info['file_size_kb']}KB")
```

### 3. 素材管理器（material_organizer.py）

**功能：**
- 创建标准化目录结构
- 自动分类文件
- 生成元数据索引
- 生成批量处理脚本

**示例：**
```python
from src.material_organizer import MaterialOrganizer

organizer = MaterialOrganizer("素材库")

# 创建目录结构
organizer.create_directory_structure()

# 分类文件
category, subcategory = organizer.classify_emoji(

# 移动文件到对应目录
target_path = organizer.move_to_category(
    "emoji_001_240x240.gif",
    category,
    subcategory
)

# 保存索引
organizer.save_indexes()
```

## ⚙️ 配置参数

### 运动检测配置

```python
motion_config = {
    "sample_interval": 5,          # 采样间隔（秒）
    "motion_threshold": 0.15,      # 运动强度阈值
    "merge_gap": 3.0,              # 合并间隔（秒）
    "min_duration": 2.0,           # 最小持续时间
    "max_duration": 10.0           # 最大持续时间
}

detector = MotionDetector(motion_config)
```

### GIF生成配置

```python
emoji_config = {
    "default_fps": 15,              # 默认帧率
    "max_size_kb": 1000,            # 最大文件大小（KB）
    "quality": 85,                  # 图片质量（1-100）
    "resize_method": "lanczos"      # 缩放方法
}

generator = EmojiGenerator(emoji_config)
```

### 多模态检测配置

```python
multimodal_config = {
    "time_window": 3.0,             # 前后时间窗口（秒）
    "emotion_weight": 0.3,          # 表情权重
    "gesture_weight": 0.4,          # 手势权重
    "effect_weight": 0.2,           # 特效权重
    "keyword_weight": 0.1,          # 关键词权重
    "recommend_threshold": 0.7      # 推荐阈值
}

detector = MultimodalDetector(multimodal_config)
```

## ❓ 常见问题

### Q1: 运行时提示"ModuleNotFoundError: No module named 'mediapipe'"

**A:** MediaPipe是可选依赖，用于精确手势识别。如果不需要方案B（姿态估计），可以跳过安装。如需安装：

```bash
pip install mediapipe>=0.10.0
```

### Q2: 生成的GIF文件太大，超过1MB

**A:** 调整生成参数：

```python
generator = EmojiGenerator({
    "default_fps": 10,      # 降低帧率
    "max_size_kb": 800      # 降低目标大小
})
```

### Q3: 手势舞检测结果太少

**A:** 降低运动阈值：

```python
detector = MotionDetector({
    "motion_threshold": 0.10  # 从0.15降低到0.10
})
```

### Q4: 感谢时刻检测不准确

**A:** 调整多模态权重：

```python
detector = MultimodalDetector({
    "emotion_weight": 0.2,
    "gesture_weight": 0.5,    # 增加手势权重
    "effect_weight": 0.3      # 增加特效权重
})
```

### Q5: 如何只生成某种规格的GIF？

**A:** 自定义规格：

```python
custom_specs = {
    "medium": (300, 300)  # 只生成300x300
}

result = generator.generate_multi_specs(
    ...,
    specs=custom_specs
)
```

## 📈 性能优化

### 1. 加快处理速度

- 跳过方案B（姿态估计）
- 减少采样点数量
- 降低GIF帧率

### 2. 提升质量

- 使用方案B进行精确识别
- 增加分析时间窗口
- 提高GIF帧率和分辨率

### 3. 减小文件大小

- 降低GIF帧率（15fps → 10fps）
- 减少颜色数量（自动优化）
- 缩短表情包时长（3s → 2s）

```
[视频文件] → [方案A：运动检测] → 15-25个候选片段
                   ↓
             [方案B：姿态估计] → 10-15个确认片段
                   ↓
             [方案C：多模态检测] → 50-60个感谢表情
                   ↓
             [表情包生成器] → 生成GIF（3种规格）+ 高清图
                   ↓
             [素材管理器] → 分类存储 + 索引
                   ↓
             [输出] → 素材库/ + 元数据 + 统计报告
```
