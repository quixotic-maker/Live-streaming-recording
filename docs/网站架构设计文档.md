## 🎯 项目概述

### 目标
构建一个多层级的素材展示和管理网站，包含：
- **主站**：综合展示所有素材
- **视频站**：完整直播录像、精彩集锦
- **歌曲站**：125首歌曲音频和视频
- **表情包站**：手势舞、感谢手势、礼物特效表情包
- **照片站**：关键帧截图

### 用户群体
- 观山粉丝
- 内容创作者
- 素材需求者

## 💾 数据库设计

### 核心表结构

#### 1. 视频表 (videos)
```sql
CREATE TABLE videos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255),
    file_path VARCHAR(500),
    duration INT,                  -- 秒
    file_size BIGINT,              -- 字节
    resolution VARCHAR(20),        -- 1920x1080
    upload_time TIMESTAMP,
    view_count INT DEFAULT 0,
    download_count INT DEFAULT 0,
    category ENUM('full', 'highlight', 'song'),
    status ENUM('active', 'archived'),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 2. 歌曲表 (songs)
```sql
CREATE TABLE songs (
    id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255),
    video_start FLOAT,             -- 视频中的起始时间
    video_end FLOAT,
    duration FLOAT,
    audio_file VARCHAR(500),       -- 音频文件路径
    video_file VARCHAR(500),       -- 视频片段路径
    lyrics_srt VARCHAR(500),       -- SRT字幕
    lyrics_ass VARCHAR(500),       -- ASS字幕
    play_count INT DEFAULT 0,
    download_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 3. 表情包表 (emojis)
```sql
CREATE TABLE emojis (
    id INT PRIMARY KEY AUTO_INCREMENT,
    category ENUM('dance', 'thanks', 'gift_effect'),
    file_type ENUM('gif', 'png', 'jpg'),
    file_path VARCHAR(500),
    file_size INT,                 -- 字节
    width INT,
    height INT,
    duration FLOAT,                -- GIF时长
    source_time FLOAT,             -- 来源视频时间
    view_count INT DEFAULT 0,
    download_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 4. 照片表 (photos)
```sql
CREATE TABLE photos (
    id INT PRIMARY KEY AUTO_INCREMENT,
    category ENUM('interval', 'scene_change', 'song', 'gift'),
    file_path VARCHAR(500),
    file_size INT,
    width INT,
    height INT,
    source_time FLOAT,             -- 截图时间点
    view_count INT DEFAULT 0,
    download_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 5. 用户表 (users) - 可选
```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE,
    email VARCHAR(100),
    password_hash VARCHAR(255),
    role ENUM('admin', 'user'),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 6. 统计表 (statistics)
```sql
CREATE TABLE statistics (
    id INT PRIMARY KEY AUTO_INCREMENT,
    date DATE,
    total_visits INT,
    total_downloads INT,
    popular_song_id INT,
    popular_emoji_id INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 🔌 API接口设计

### RESTful API规范

**Base URL:** `https://api.shanshan.com/v1`

#### 视频相关
```
GET    /videos                   # 获取视频列表
GET    /videos/:id               # 获取视频详情
GET    /videos/:id/download      # 下载视频
GET    /videos/categories/:cat   # 按类别筛选
```

#### 歌曲相关
```
GET    /songs                    # 获取歌曲列表
GET    /songs/:id                # 获取歌曲详情
GET    /songs/:id/audio          # 获取音频文件
GET    /songs/:id/lyrics         # 获取歌词
GET    /songs/:id/subtitle/:fmt  # 获取字幕 (srt/ass)
```

#### 表情包相关
```
GET    /emojis                   # 获取表情包列表
GET    /emojis/:id               # 获取表情包详情
GET    /emojis/:id/download      # 下载表情包
GET    /emojis/categories/:cat   # 按类别筛选
```

#### 照片相关
```
GET    /photos                   # 获取照片列表
GET    /photos/:id               # 获取照片详情
GET    /photos/:id/download      # 下载照片
GET    /photos/categories/:cat   # 按类别筛选
```

#### 统计相关
```
GET    /stats/summary            # 总体统计
GET    /stats/popular            # 热门内容
POST   /stats/track              # 记录访问/下载
```

## 🎨 前端设计要求

### 主站首页
- **顶部导航**：主站、视频站、歌曲站、表情包站、照片站
- **轮播图**：精彩集锦视频预览
- **分类展示**：各类素材卡片式展示
- **搜索功能**：全站搜索
- **统计信息**：总视频数、总歌曲数、总访问量

### 视频站
- **列表视图**：缩略图 + 标题 + 时长 + 播放次数
- **视频播放器**：支持倍速、全屏、下载
- **分类筛选**：完整录像、精彩集锦、歌曲视频
- **时间线标记**：显示唱歌/礼物/闲聊时段

### 歌曲站
- **歌曲列表**：序号 + 歌名 + 时长 + 播放按钮
- **在线播放器**：音频播放器（支持歌词显示）
- **下载选项**：MP3、FLAC、视频、字幕
- **搜索功能**：按歌名搜索

### 表情包站
- **瀑布流布局**：自适应网格显示
- **分类标签**：手势舞、感谢手势、礼物特效
- **预览功能**：鼠标悬停播放GIF
- **下载功能**：支持批量下载
- **规格显示**：尺寸、文件大小

### 照片站
- **图片墙**：网格布局
- **灯箱效果**：点击放大查看
- **时间线导航**：按视频时间轴浏览
- **下载功能**：原图下载

## 🚀 部署架构

### 推荐配置

**服务器：**
- CPU: 4核以上
- 内存: 8GB以上
- 硬盘: 500GB以上（视素材量增长）
- 带宽: 100Mbps以上

**软件栈：**
- 操作系统: Ubuntu 22.04 LTS
- Web服务器: Nginx 1.24+
- 应用服务器: FastAPI / Node.js
- 数据库: MySQL 8.0+ / PostgreSQL 14+
- 缓存: Redis 7.0+
- CDN: （可选）阿里云OSS、腾讯云COS

### 部署流程

```bash
# 1. 环境准备
sudo apt update && sudo apt upgrade -y
sudo apt install nginx mysql-server python3-pip

# 2. 数据库初始化
mysql -u root -p < database_schema.sql

# 3. 素材同步
rsync -avz ~/shanshan_materials/ /var/www/shanshan/media/

# 4. 启动服务
cd /var/www/shanshan/api
uvicorn main:app --host 0.0.0.0 --port 8000

# 5. Nginx配置
sudo systemctl reload nginx
```
