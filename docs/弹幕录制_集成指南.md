# 弹幕录制集成指南

## 📋 概述

弹幕录制系统用于实时记录直播间的弹幕、礼物、升级等事件，为后续的内容分析、升级检测、弹幕对齐提供数据基础。

---

## 🏗️ 架构设计

### 核心模块

```
src/
├── danmaku_recorder.py      # 弹幕录制器基类
└── danmaku_douyin.py         # 抖音专用实现
```

### 数据流

```
直播间 → WebSocket/HTTP → 弹幕录制器 → 数据文件
                                    ↓
                              事件检测器
                                    ↓
                          升级/礼物事件回调
                                    ↓
                          其他系统处理
```

```python
import sys
sys.path.append('/home/liu/app_github/DouyinBarrageGrab')

try:
    from douyin_barrage import DouyinBarrage
    HAS_DOUYIN_BARRAGE = True
except ImportError:
    HAS_DOUYIN_BARRAGE = False

class DouyinDanmakuRecorder:
    def _websocket_record_loop(self):
        if not HAS_DOUYIN_BARRAGE:
            logger.error("DouyinBarrageGrab未安装")
            return
        
        # 创建弹幕抓取器
        barrage = DouyinBarrage(self.room_id)
        
        # 设置消息回调
        @barrage.on_message
        def on_message(data):
            self.process_message(data)
        
        # 开始抓取
        barrage.start()
        
        # 等待停止
        while self.is_recording:
            time.sleep(1)
        
        barrage.stop()
```

## 🎯 升级检测逻辑

### 检测策略

弹幕录制器使用以下策略检测升级事件：

#### 1. 关键词匹配

```python
upgrade_patterns = [
    r'升到\s*(\d+)\s*级',      # "升到16级"
    r'达到\s*(\d+)\s*级',      # "达到18级"
    r'lv\s*(\d+)',             # "LV16"
    r'(\d+)\s*级.*粉丝'        # "16级粉丝"
]
```

#### 2. 等级过滤

只记录 **16级及以上** 的升级事件（可配置）

```python
if level >= 16:
    # 记录升级事件
```

#### 3. 多源验证

- 主要来源：聊天消息中的系统通知
- 辅助来源：成员消息、社交消息
- 后续：可以结合语音识别进一步确认

## 🐛 故障排除

### 问题1: websockets库未安装

**错误**:
```
ModuleNotFoundError: No module named 'websockets'
```

**解决**:
```bash
pip install websockets websocket-client
```

---

### 问题2: 无法获取WebSocket URL

**原因**: 抖音直播的WebSocket连接需要特殊的签名和参数

**解决**: 集成DouyinBarrageGrab项目（见上文）

---

### 问题3: 弹幕录制不工作

**检查清单**:
1. ✅ 直播间是否正在直播
2. ✅ 房间ID是否正确
3. ✅ 网络连接是否正常
4. ✅ 是否有权限写入输出目录
5. ✅ 是否安装了必要的依赖

---

### 问题4: 升级事件检测不准确

**优化方案**:
1. 调整关键词匹配规则
2. 结合语音识别
3. 多源验证（弹幕+语音+视觉）
