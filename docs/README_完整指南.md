# 📖 观山直播素材管理系统 - 完整指南

## 🎯 项目概述

这是一个完整的直播录制和素材管理系统，包含：
- ✅ 自动直播录制（时间窗口监控）
- ✅ 视频自动分段和合并
- ✅ AI内容分类（唱歌/礼物/闲聊）
- ✅ 歌曲识别和提取（125首）
- ✅ 表情包生成系统
- ✅ 关键帧截图
- ✅ 精彩集锦自动生成
- ✅ 歌词字幕生成
- ✅ 剪映草稿自动生成
- ✅ 网站集成文档

**开发完成日期：** 2025-10-31  
**版本：** v1.0

## 🚀 快速开始

### 1. 直播录制（立即可用）

```bash
cd /home/liu/app_github/DouyinLiveRecorder

# 启动直播录制
```

- 录制保存：`downloads/` 目录

### 2. 素材处理（一键运行）


1. 内容分类（唱歌/礼物/闲聊）
2. 歌曲识别和整理
3. 提取歌曲音频（MP3+FLAC）
4. 生成歌词字幕（SRT+ASS）
5. 提取关键帧截图
6. 生成精彩集锦（1/3/5分钟）

### 3. 健康检查


## ❓ 常见问题

### Q1: 如何修改录制时间？
**A:** 编辑 `config/config.ini`，修改：
```ini
监测开始时间 = 19:01
监测结束时间 = 23:30
```

### Q2: 素材存储在哪里？
**A:** 统一存储在 `~/shanshan_materials/`

### Q3: 如何生成表情包？
**A:** 运行：`python3 生成表情包素材_优化版.py`

### Q4: 剪映草稿如何使用？
**A:** 
1. 生成草稿：`python3 生成剪映草稿_歌曲集锦.py`
2. 打开剪映专业版
3. 导入草稿目录：`~/shanshan_materials/剪映草稿/`

### Q5: 如何批量处理素材？
**A:** 运行：`bash 一键运行所有脚本.sh`

### Q6: 磁盘空间不足怎么办？
**A:** 
- 删除旧的录像文件
- 删除分段文件（如已合并）
- 清理临时文件
- 扩容硬盘

## 🚨 注意事项

1. **录制前确认**：
   - 检查URL是否正确（`config/URL_config.ini`）
   - 确保有足够磁盘空间（至少50GB）
   - 检查FFmpeg是否安装

2. **素材处理**：
   - 第一次处理建议使用一键脚本
   - 表情包生成耗时较长，建议单独运行
   - 定期备份重要素材

3. **性能考虑**：
   - 录制+处理同时进行会占用较多资源
   - 建议录制完成后再进行素材处理
   - 大批量处理建议在服务器上运行
