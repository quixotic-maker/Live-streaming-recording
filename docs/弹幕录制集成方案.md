### 步骤2：修改 DouyinLiveRecorder/main.py

在 `main.py` 中添加弹幕录制线程：

```python
# 在文件开头导入
import threading
import subprocess

def start_danmaku_recording(room_url, output_file):
    """
    启动弹幕录制
    
    Args:
        room_url: 直播间URL
        output_file: 输出文件路径
    """
    try:
        cmd = [
            'python3',
            '/home/liu/app_github/DouyinBarrageGrab/main.py',
            '--room_url', room_url,
            '--output', output_file
        ]
        subprocess.run(cmd)
    except Exception as e:
        print(f"弹幕录制错误: {e}")

# 在录制开始时启动弹幕线程
def start_recording_with_danmaku(video_url, room_url, output_dir):
    """
    同时启动视频录制和弹幕录制
    """
    timestamp = time.strftime("%Y-%m-%d_%H-%M-%S")
    
    # 视频输出路径
    video_output = os.path.join(output_dir, f"观山_{timestamp}.ts")
    
    # 弹幕输出路径
    danmaku_output = os.path.join(output_dir, f"观山_{timestamp}_弹幕.json")
    
    # 启动弹幕录制线程
    danmaku_thread = threading.Thread(
        target=start_danmaku_recording,
        args=(room_url, danmaku_output),
        daemon=True
    )
    danmaku_thread.start()
```

## 💡 技术要点

### 1. 时间戳同步

**问题**：视频录制和弹幕录制是两个独立进程，时间可能不同步。

**解决方案**：
```python
# 方案A：使用统一的起始时间戳
start_timestamp = time.time()

# 在弹幕记录中：
danmaku['relative_time'] = time.time() - start_timestamp

# 在视频中可以通过FFmpeg获取相对时间
```

### 2. 数据持久化

**建议结构**：
```
~/shanshan_materials/弹幕数据/
├── 2025-10-30/
│   ├── 观山_2025-10-30_19-01-00_弹幕.json  （原始）
│   ├── 观山_2025-10-30_19-01-00_弹幕_分析.json  （分析结果）
│   └── 观山_2025-10-30_19-01-00_弹幕统计.txt
└── ...
```

### 3. 容错机制

```python
# 弹幕录制失败不应影响视频录制
try:
    danmaku_thread.start()
except Exception as e:
    logger.error(f"弹幕录制启动失败: {e}")
    # 继续视频录制
```
