## 📁 素材文件命名规范

### 视频文件
```
格式: {主播名}_{日期}_{类型}.{扩展名}
示例:
  - 观山_2025-10-30_完整.mp4
  - 观山_2025-10-30_精彩集锦_3分钟.mp4
  - 观山_2025-10-30_歌曲_晴天.mp4
```

### 音频文件
```
格式: {序号}_{歌名}.{扩展名}
示例:
  - 001_晴天.mp3
  - 001_晴天.flac
  - 002_七里香.mp3
```

### 表情包文件
```
格式: {类型}_{序号}_{尺寸}.{扩展名}
示例:
  - dance_001_240.gif
  - thanks_012_300.gif
  - gift_effect_005_512.gif
  - dance_001_static.jpg
```

### 截图文件
```
格式: screenshot_{时间秒数}s.jpg
或: scene_{时间秒数}s_diff{差异分数}.jpg
示例:
  - screenshot_001200s.jpg
  - scene_001800s_diff35.2.jpg
```

### 字幕文件
```
格式: {序号}_{歌名}.{srt|ass}
示例:
  - 001_晴天.srt
  - 001_晴天.ass
```

## 📝 JSON数据格式

### 1. 歌曲列表 (歌曲素材库/歌曲列表.json)

```json
{
  "total_songs": 125,
  "total_duration": 22425.5,
  "generated_at": "2025-10-31T11:48:00Z",
  "source_video": "/path/to/观山_2025-10-30.mp4",
  "songs": [
    {
      "id": 1,
      "title": "晴天",
      "start": 300.5,
      "end": 480.2,
      "duration": 179.7,
      "text": "故事的小黄花 从出生那年就飘着...",
      "metadata": {
        "genre": "流行",
        "mood": "温柔",
        "original_artist": "周杰伦"
      }
    }
  ]
}
```

**字段说明：**
| 字段 | 类型 | 说明 |
|-----|------|------|
| total_songs | int | 总歌曲数 |
| total_duration | float | 总时长（秒） |
| generated_at | string | 生成时间（ISO 8601） |
| source_video | string | 源视频路径 |
| songs | array | 歌曲数组 |
| songs[].id | int | 歌曲ID |
| songs[].title | string | 歌曲名称 |
| songs[].start | float | 起始时间（秒） |
| songs[].end | float | 结束时间（秒） |
| songs[].duration | float | 持续时间（秒） |
| songs[].text | string | 歌词片段 |

### 2. 分类素材 (素材库_最新/*.json)

```json
{
  "category": "singing",

**字段说明：**

| total_count | int | 总片段数 |

```

## 📄 字幕格式规范

### SRT格式
```srt
1
00:00:00,000 --> 00:00:05,500
故事的小黄花 从出生那年就飘着

2
00:00:05,500 --> 00:00:10,200
童年的荡秋千 随记忆一直晃到现在
```

**规范：**
- 编码: UTF-8 (无BOM)
- 换行: LF (\n)
- 时间格式: HH:MM:SS,mmm
- 每行不超过42个字符

### ASS格式
```ass
[Script Info]
Title: 歌词字幕
ScriptType: v4.00+

[V4+ Styles]
Format: Name, Fontname, Fontsize, ...
Style: Default,Arial,24,&H00FFFFFF,...

[Events]
Format: Layer, Start, End, Style, Name, ...
Dialogue: 0,0:00:00.00,0:00:05.50,Default,,0,0,0,,故事的小黄花...
```

**规范：**
- 编码: UTF-8 (无BOM)
- 换行: LF (\n)
- 时间格式: H:MM:SS.cc
- 支持样式和特效

## 🗂️ 目录结构规范

### 标准目录结构
```
素材根目录/
├── videos/                    # 视频文件
│   ├── full/                  # 完整录像
│   ├── highlights/            # 精彩集锦
│   └── songs/                 # 歌曲视频
│
├── audio/                     # 音频文件
│   ├── mp3/                   # MP3格式
│   └── flac/                  # FLAC格式
│
├── emojis/                    # 表情包
│   ├── dance/                 # 手势舞
│   ├── thanks/                # 感谢手势
│   └── gift_effect/           # 礼物特效
│
├── photos/                    # 照片
│   ├── interval/              # 固定间隔
│   ├── scene_change/          # 场景变化
│   ├── songs/                 # 歌曲时刻
│   └── gifts/                 # 礼物时刻
│
├── subtitles/                 # 字幕
│   ├── srt/                   # SRT格式
│   └── ass/                   # ASS格式
│
└── metadata/                  # 元数据
    ├── videos.json            # 视频索引
    ├── songs.json             # 歌曲索引
    ├── emojis.json            # 表情包索引
    └── photos.json            # 照片索引
```

## ✅ 数据校验规则

### 必填字段
所有JSON文件必须包含：
- `generated_at`: 生成时间
- 对应的资源数组或对象

### 时间格式
- ISO 8601格式：`2025-10-31T15:00:00Z`
- 视频时间戳：浮点数（秒）

### 文件路径
- 使用绝对路径或相对于根目录的路径
- 路径分隔符：统一使用 `/`
- 中文文件名：UTF-8编码

### 文件大小
- 所有size字段单位：字节（Bytes）
- 使用整数类型

### 数值精度
- 时间：保留1位小数
- 百分比：保留2位小数
- 文件大小：整数

## 🔄 版本控制

### 数据格式版本号
```
格式: v{主版本}.{次版本}
当前: v1.0

主版本变更：不兼容的结构变化
次版本变更：向后兼容的新增字段
```

### 兼容性保证
- 所有v1.x版本向后兼容
- 新增字段为可选
- 删除字段需主版本升级
