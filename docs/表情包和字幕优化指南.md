# 表情包文字添加 & 字幕校对 - 使用指南

## 📋 新增工具说明

针对您提出的两个重要问题，我们新增了两个工具：

### 🎨 工具1：表情包文字添加 (`表情包添加文字.py`)
**问题：** 表情包只有图像，没有文字  
**解决：** 自动/半自动为表情包添加文字

### 📝 工具2：字幕校对工具 (`字幕校对工具.py`)
**问题：** Whisper语音识别可能有错误  
**解决：** 自动纠错 + 交互式人工校对

## 🎨 表情包文字添加

### 功能特点

1. **三种模式：**
   - 自动模式：使用预设文字库
   - 半自动模式：从候选列表选择
   - 自定义模式：手动输入每个文字

2. **预设文字库：**
   - 手势舞：手势舞、来跳舞、666、太强了、会跳舞...
   - 感谢手势：谢谢、谢谢老板、爱你们、感谢支持、么么哒...
   - 礼物特效：哇、豪气、大气、土豪、壕无人性...

3. **文字样式：**
   - 白色文字 + 黑色描边（易读）
   - 支持顶部/居中/底部位置
   - 自动字体大小
   - 支持GIF和静态图

### 使用方法

```bash
# 运行工具
python3 表情包添加文字.py

# 按提示选择：
# 1. 选择模式（自动/半自动/自定义）
# 2. 选择类别（手势舞/感谢手势/礼物特效）
# 3. 自动处理或交互式添加文字
```

### 使用示例

#### 示例1：自动模式（最快）
```bash
python3 表情包添加文字.py

选择模式: 1 (自动)
选择类别: 1 (手势舞)

# 自动为所有表情包添加预设文字
# 输出：~/shanshan_materials/表情包素材库/手势舞_带文字/
```

#### 示例2：半自动模式（推荐）
```bash
python3 表情包添加文字.py

选择模式: 2 (半自动)
选择类别: 2 (感谢手势)

# 对每个表情包：
# 显示候选文字列表
# 1. 谢谢
# 2. 谢谢老板
# 3. 爱你们
# ...
# 选择一个或自定义
```

#### 示例3：自定义模式（最灵活）
```bash
python3 表情包添加文字.py

选择模式: 3 (自定义)
选择类别: 3 (礼物特效)

# 对每个表情包手动输入文字
# 可以针对性地添加不同文字
```

### 文字效果

**自动优化：**
- ✅ 白色文字 + 黑色描边（对比度高）
- ✅ 自动居中对齐
- ✅ 文字大小自适应
- ✅ GIF所有帧添加文字
- ✅ 保持原图质量

**位置选项：**
- 默认：底部（不遮挡主体）
- 可选：顶部、居中

## 📝 字幕校对工具

### 为什么需要校对？

Whisper虽然准确率高，但仍可能出现：
1. **同音字错误**：观山 → 官山、冠山
2. **口语识别错误**：家人们 → 家人门
3. **歌词识别错误**：故事 → 故是
4. **标点符号问题**：重复标点、缺少标点
5. **乱码和特殊字符**

### 功能特点

#### 1. 自动检测问题
- ✅ 低置信度片段
- ✅ 过短/过长片段
- ✅ 重复文本
- ✅ 可疑字符（乱码）
- ✅ 标点符号问题

#### 2. 自动纠错
- ✅ 常见错误词典（可自定义）
- ✅ 标点符号规范化
- ✅ 多余空格清理
- ✅ 敏感词过滤

#### 3. 交互式校对
- ✅ 只显示有问题的片段
- ✅ 提供自动纠错建议
- ✅ 一键应用或手动修改
- ✅ 可随时跳过

#### 4. 生成报告
- ✅ 问题统计
- ✅ 修正记录
- ✅ 改进建议

### 使用方法

```bash
# 运行工具
python3 字幕校对工具.py

# 按提示操作：
# 1. 选择字幕来源（JSON或SRT）
# 2. 自动检测问题
# 3. 选择校对模式（自动/交互）
# 4. 保存校对后的字幕
```

### 使用示例

#### 示例1：仅自动纠错（快速）
```bash
python3 字幕校对工具.py

选择来源: 1 (Whisper JSON)
选择模式: 1 (仅自动纠错)

# 自动应用错误词典和规范化
# 输出：~/shanshan_materials/歌词字幕_校对后/
```

#### 示例2：交互式校对（推荐）
```bash
python3 字幕校对工具.py

选择来源: 1 (Whisper JSON)
选择模式: 2 (交互式)

# 只显示有问题的片段
# 每个片段：
#   - 显示原文
#   - 显示问题类型
#   - 显示自动纠错建议
#   - 选择：保持/修改/应用建议
```

### 自定义错误词典

编辑 `字幕校对工具.py`，在 `error_dict` 中添加：

```python
self.error_dict = {
    # 添加您发现的常见错误
    "观沙": "观山",     # 主播名字
    "家人门": "家人们",  # 口语
    "故是": "故事",      # 歌词
    # ... 更多
}
```

每次校对后，记录发现的新错误，持续优化词典。

### 校对输出

```
~/shanshan_materials/歌词字幕_校对后/
├── 字幕_校对后.srt         # SRT格式（通用）
├── 字幕_校对后.json        # JSON格式（备份）
└── 校对报告.txt            # 详细报告
```

## 💡 最佳实践

### 表情包文字添加

#### 推荐工作流：
```
1. 先生成表情包（无文字）
   python3 生成表情包素材_优化版.py

2. 筛选优质表情包
   手动查看，删除不满意的

3. 添加文字
   python3 表情包添加文字.py
   使用半自动模式，针对性添加

4. 最终检查
   预览效果，调整不满意的
```

#### 文字选择建议：
- **手势舞**：简短有力（如"666"、"太强了"）
- **感谢手势**：温暖亲切（如"谢谢老板"、"爱你们"）
- **礼物特效**：夸张有趣（如"壕无人性"、"土豪"）

#### 注意事项：
- 文字不要太长（≤6个字）
- 避免遮挡关键内容
- 颜色对比要明显
- GIF文件大小控制（≤500KB）

### 字幕校对

#### 推荐工作流：
```
1. 生成原始字幕
   （已通过 生成歌词字幕.py 完成）

2. 首次运行自动纠错
   python3 字幕校对工具.py
   选择"仅自动纠错"

3. 查看自动纠错结果
   检查修改是否合理

4. 交互式精细校对
   python3 字幕校对工具.py
   选择"交互式校对"
   重点校对低置信度片段

5. 更新错误词典
   将发现的新错误加入词典

6. 后续字幕生成
   直接运行字幕校对工具
   准确率逐步提升
```

#### 提高准确率的方法：

**方法1：使用更大的Whisper模型**
```python
# 在完整语音分析.py中修改
model = whisper.load_model("large")  # 改为large
# 准确率提升，但速度变慢
```

**方法2：持续更新错误词典**
```python
# 每次发现新错误就添加
self.error_dict["错误词"] = "正确词"
```

**方法3：分类处理**
- 歌曲字幕：重点校对歌词
- 闲聊字幕：允许口语化
- 礼物感谢：统一格式

**方法4：二次校对**
- 第一遍：自动纠错
- 第二遍：人工精校
- 第三遍：最终审核

## ⚙️ 配置和扩展

### 添加新的预设文字

编辑 `表情包添加文字.py`：

```python
self.preset_texts = {
    "dance": [
        "手势舞", "来跳舞", "666",
        # 添加您的新文字
        "跟我学", "太酷了", "绝了"
    ],
    # ... 其他类别
}
```

### 添加新的错误词

编辑 `字幕校对工具.py`：

```python
self.error_dict = {
    # 根据实际情况添加
    "您的错误": "正确的词",
}
```

### 调整文字样式

编辑 `表情包添加文字.py` 中的参数：

```python
# 文字大小
font_size = 32  # 调大或调小

# 文字颜色（RGB）
text_color = (255, 255, 255)  # 白色
# text_color = (255, 215, 0)  # 金色
# text_color = (255, 105, 180)  # 粉色

# 描边颜色
outline_color = (0, 0, 0)  # 黑色

# 描边宽度
outline_width = 2  # 增加描边宽度

# 位置
position = "bottom"  # top/center/bottom
```

## 🔧 故障排除

### 表情包工具

**问题1：字体显示异常**
```
原因：未找到中文字体
解决：安装中文字体
sudo apt install fonts-wqy-microhei
```

**问题2：GIF文件过大**
```
原因：帧数过多或尺寸过大
解决：使用较小尺寸（240px）或减少帧数
```

**问题3：文字被遮挡**
```
原因：位置设置不当
解决：调整position参数（top/center/bottom）
```

### 字幕校对工具

**问题1：检测问题过多**
```
原因：阈值设置过严格
解决：调整检测阈值
```

**问题2：自动纠错效果不佳**
```
原因：错误词典不完善
解决：持续更新错误词典
```

**问题3：交互式校对太慢**
```
原因：需要逐个审核
解决：先用自动模式，只对关键片段交互校对
```
